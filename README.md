# control-plus-backend

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.4.2. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

Si se presentan errores de typescript en los modulos de node ejecutar:

```bash
    npm i --save-dev @types/modulo-que-presenta-error
```
